# noahtolly.co.uk

Personal site for Noah Tolly: stage lighting and web design. A single-page
lander built for people scanning the QR code on his business card.

Plain HTML, CSS and JavaScript, no framework, no build step, no external
dependencies. Deployable as-is to GitHub Pages or any static host.

## Structure

```
index.html
css/style.css
js/main.js
assets/img/
```

## Local preview

```
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
